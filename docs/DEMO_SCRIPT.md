# StarScore 两分钟比赛演示脚本

## v0.2.0 银河相遇版

1. **0:00—0:20** 打开默认银河，跳过星光穿行；点“拾光星云”试听原创星谱，说明是本机示例居民。
2. **0:20—0:40** 点“以此为灵感”，展示独立副本和返回具体作者星云的来源导航。
3. **0:40—1:05** 拖动星点，调整时值/力度，打开低音与鼓，播放 Tone.js 四小节。
4. **1:05—1:30** 生成 A/B，明确显示 `rules` 或真实 `model` 来源；试听、采用、撤销、重做。
5. **1:30—1:50** 保存作品，发布本机星云，导出 `.starscore-galaxy.json`。
6. **1:50—2:00** 展示 Android APK、JSON/MIDI 和公开仓库。无模型配置时不得把规则回应称作在线 AI。

## 演示前准备

- 打开已保存的“夜航”或经人工试听签字的正式演示副本，确认 API 健康、音量和声部开关。
- 当前无真实模型凭据时固定选择“规则演示”，全程口播和界面都不得称为真实 AI。
- 若真实模型已验收，先确认界面来源显示 `model`，并准备规则模式作为网络失败回退。

## 0:00–0:20 绘制星图

“星谱把旋律变成可以触摸的星图。我点出几个星点，纵向就是音高，星尾是时值，光晕是力度。”点出 4–6 颗星并拖动其中一颗，展示吸附到 C 大调五声音阶。

## 0:20–0:38 听原旋律

点击播放：“这里不是动画预览，星点、低音和八格鼓环共享同一音乐时钟。”播放约一个乐句后停止，快速切换一个伴奏声部展示独立开关。

## 0:38–1:02 生成两个回应

点击“生成回应”。口播：“前两小节保持原旋律，系统只在后两小节生成两个合法回应。”明确指出来源徽标：“现在显示的是规则演示”或“这里显示真实模型回应，来源为 model”。

## 1:02–1:24 比较试听

依次试听 A、B，每个播放关键片段：“试听会播放原旋律加当前候选，但不会改动作品。”指出紫色虚线星点是未采用候选。

## 1:24–1:42 采用与演奏

采用较合适的候选，进入演奏页：“采用是一个可撤销操作；原旋律不变，回应才写入项目。”短暂演奏完整作品，展示暖色播放提示。

## 1:42–2:00 保存与导出

返回画室，演示撤销/重做一次，再保存。点击 JSON 与 MIDI：“JSON 保留可编辑星图，MIDI 是 90 BPM、4/4、三声部、两轮八小节，可继续进入制作流程。”若在 Android 上，展示系统分享面板。

## 失败回退台词

“真实模型当前不可用，作品不会被覆盖。现在切换到明确标注的规则演示继续完成流程。”不要隐藏错误、伪造 model 来源或在展示机中输入服务端密钥。
